App 5 · Play

20 Questions, refereed by Jev in real time

Jev is thinking of something. Ask yes/no questions or name your guess. Each turn is one request with four questions asked at once, and the answer you see is a threshold on a calibrated probability, which is why Jev can say “probably” and mean it.

What happens each turn

The state is {secret, player_question}. Four Noul questions run in parallel:

  • answer_is_yes — the honest yes/no answer for the secret thing
  • is_yes_no_question — did you actually ask a yes/no question?
  • names_a_guess — are you naming a specific thing?
  • guess_matches — does your guess mean the same thing as the secret?

Code maps P(yes) to Yes ≥ 85%, Probably ≥ 60%, Hard to say, Probably not ≤ 40%, No ≤ 15%. A guess wins when both guess Nouls agree. The secret stays on the server; the request traces are released when the game ends.

Why this is interesting

A game turn costs about a hundred tokens, so a whole game is a fraction of a cent, and each answer arrives fast enough to feel like a person is answering.

The same shape (hidden state + a player's free text → typed judgments) runs interactive tutorials, quizzes, escape-room puzzles, and NPC dialogue without a text-generating model in the loop.
