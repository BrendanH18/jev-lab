TypeSafe · Jev · a System One model

AI that answers in types, not paragraphs.

Jev isn't a chatbot. You give it some context and a list of questions with fixed answer options. It returns a choice, a score, or a probability for each one, and your code branches on those directly. There's no prose to parse and no agent loop. It works like a quick gut check that your program can call, about a hundred milliseconds at a time.

Typed by construction

Every answer is one of the options you defined, along with the full probability distribution. It never returns a value outside your schema.

Many questions, one call

Questions are evaluated in parallel and independently of each other against the same context, so adding more questions barely adds latency.

Calibrated confidence

The probabilities are trained to reflect real uncertainty, so your code can decide when to act, when to ask, and when to escalate.

Fast and cheap

TypeSafe's docs say most queries take about 100 ms and cost $0.042 per million input tokens, with output free. Every page here shows the latency and cost it actually measured.

Built the way TypeSafe recommends

Jev has known weak spots, and these apps are built to avoid them. TypeSafe's docs list them.

Math, dates, and exact values stay in code

Dollar amounts and times are found with regex, and Jev picks which one the request means. Refund windows, invoice matching, and balances are plain arithmetic.

Narrow questions, composed in code

"Is this a scam?" is broken into small questions: does it redirect a payment, who does the sender claim to be, does it pressure you? A weighted formula you can edit combines them.

Jev selects, it doesn't generate

Replies come from templates Jev picks. Task text is copied from the request. Nothing in these apps asks Jev to write prose.
