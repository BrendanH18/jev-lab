How the verdict is computed

Each signal's probability × weight is combined with a noisy-OR, risk = 1 − Π(1 − wᵢ·pᵢ), so a single strong signal is enough to raise risk.

Hard rules run on their own. For example, any message aimed at an AI assistant is quarantined, whatever the weights say.

The sender-domain check is ordinary string comparison. Jev only answers who the sender claims to be, and code checks whether the email domain matches.
