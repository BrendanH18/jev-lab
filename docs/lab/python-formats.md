## Row formats for Bulk rows files

Pack `row-formats` on `python.formats`. Parsers and renderers that read and write Bulk rows (text or objects, labels under _expect, held-out rows marked _test, pictures under _image) as JSON lines, a JSON array, CSV, TSV, semicolon CSV, pipe-separated text, Excel CSV with a byte-order mark, Markdown and HTML tables, and plain text lines. `lab.py rows convert` and the other rows commands use them.
