Thirty-two converters and inspectors for Bulk rows and pasted tables: CSV, TSV, Markdown and JSON arrays to rows and back, moving labels in and out, deduplicating by input, splitting and counting. They work on the pasted text only, never invent or choose between labels, never show a held-out row's label values in a report, and send nothing anywhere.

## Threshold what-ifs

Pack `tb-thresholds` on `workbench.toolbox`. Toolbox calculators for choosing and checking gate thresholds from pasted confidence,correct pairs, label,choice,confidence rows or several questions' confidences: threshold moves, lower bounds, costs, error budgets, risk-coverage, edge rows, per-choice thresholds, review bands and multi-question gates. They read only what you paste into them and never call the model; results describe the pasted rows, not new traffic.
