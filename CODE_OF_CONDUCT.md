# Code of Conduct

Jev Lab welcomes contributors of all experience levels and backgrounds. This code applies to
project issues, pull requests, reviews, and other spaces maintained by the project, as well as
public interactions when someone is representing the project.

## Expected behavior

- Be respectful, patient, and clear. Critique ideas and code without attacking people.
- Make room for questions and different perspectives. Give actionable feedback.
- Respect privacy and consent. Share only data you have permission to publish.
- Focus discussions on the project and help keep collaboration constructive.

Harassment, discriminatory language, threats, personal attacks, unwanted sexual attention,
publication of private information, and repeated disruption are unacceptable.

## Reporting and moderation

Report concerns through a private contact channel listed on the
[maintainer's profile](https://github.com/BrendanH18). If none is available, open an issue asking
for a private contact method without identifying affected people or posting incident details.
Security vulnerabilities should follow [SECURITY.md](SECURITY.md).

Maintainers may edit or remove inappropriate content, ask participants to change their behavior,
or restrict participation for repeated or serious violations. They will consider context, explain
moderation decisions when practical, and handle reports with discretion. Report details should
be shared only as needed to investigate and respond; absolute confidentiality cannot be guaranteed.
